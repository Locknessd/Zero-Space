## Mixed-source driver audit

`KB_Punches.fbx` and `KB_Kicks.fbx` are Humanoid sources. `Assets/Editor/CombatExpansionKbComboStudy.Sources.cs` resolves clips from one hard-coded punch path; `Assets/Editor/CombatExpansionHumanoidStudyDrivers.cs` accepts one model path plus a clip array, so those helpers do not automatically mix FBXs. An authoring pass must resolve exact clips from both paths and feed them to one compatible Humanoid driver.

`Assets/DemoSence/Runtime/FrankAttackTrack.cs` stores `AnimationClip` per step, and `FrankBattlePairPlayback` uses the optional track through `SetAttackTrack`; this supports separate imported clip references at the API level. Distinct source rigs still require retargeted seam validation. The required authoring change is a two-path exact-identity resolver and explicit step timing/link authoring. Runtime changes are needed only if a desired schedule cannot fit the current track contract.
